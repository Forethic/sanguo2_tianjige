【软件特性】
1. 自带 .NET 9 运行环境：完全独立，无需用户手动安装任何 .NET Runtime 或额外依赖。
2. 黄金 4:3 视口与净黑区侧边 HUD：物理零遮挡，告别全屏拉伸形变与黑边浪费。
3. 纯只读 Win32 RPM 战局参谋：实时推演城池防守、武将战力天梯、兵种相克、逆向习得速查。
4. 原生 1:1 硬件光标驱动：彻底杜绝老游戏在现代高分屏下的光标粘连与拉拽感。

【快速上手】
1. 解压压缩包到一个没有权限限制的文件夹（如 D:\Games\Tianjige）。
2. 双击运行 Tianjige.exe。
3. 首次启动请点击“浏览”，选择电脑中的《三国群英传2》根目录（包含 Sango2.exe）。
4. 选择游戏主屏与边框模式（推荐开启“有边框窗口”与“光标自由穿梭”）。
5. 点击底栏【启程 · 征战天下】大按钮，即可同时唤醒游戏与右侧天机阁参谋台！

【常见问题】
Q: 为什么游戏启动后鼠标依然可以自由移入右侧天机阁？
A: 天机阁已注入光标自由穿梭引擎（devmode），无需按 Alt+Tab 切屏即可在游戏与天机阁之间无缝操作。

Q: 找不到 Sango2.exe 怎么办？
A: 支持 Steam 版、原版光盘版及各类通用 MOD 目录，只需选定包含 Sango2.exe 的目录即可。
