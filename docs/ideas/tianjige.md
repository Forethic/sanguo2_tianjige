# 天机阁（Tianjige）：《三国群英传2》数字化军师参谋系统

## Problem Statement（问题定义）
如何在不破坏《三国群英传2》原生运行稳定性与玩家自主决策乐趣的前提下，将 4:3 复古画面在现代 16:9 显示器拉伸留下的废弃黑边，转化为一套高沉浸、零遮挡、纯客观的汉末古风数字化军师参谋工作台？

---

## Recommended Direction（推荐方案方向）
**“一体化启动台 + 画面左置 480px 宽幅屏风 + 纯只读实时内存雷达”**

1. **双窗体分离架构（Dual-Window Architecture）：**
   * **【聚贤议政台】（LauncherWindow 启动与配置台）：** 标准桌面窗口。负责游戏路径配置、`cnc-ddraw` 组件管理、多屏与任意分辨率可视化拓扑预览、HUD 尺寸/停靠位置个性化微调，以及单机离线典籍查阅。点击“启程入局”一键写配置、拉起游戏并唤醒 HUD。
   * **【军师参谋屏风】（TacticalHudWindow 实时战局 HUD）：** 无边框轻量置顶悬浮窗。专职负责战时 100% 物理零遮挡的情报呈现（实时内存雷达、技能长卷、兵机相克罗盘）。与游戏生命周期联动，游戏关闭时优雅收回。

2. **多屏与任意分辨率自适应算法（Resolution-Independent Geometry）：**
   * **非固定 1080p 纯算力适配：** 兼容 2K（2560×1440）、4K（3840×2160）、16:10（1920×1200）及笔记本（1366×768）等任意屏幕。
   * **4:3 等比视口推导公式：**
     * 游戏高度 $H_{game} = H_{screen}$
     * 游戏宽度 $W_{game} = \lfloor H_{screen} \times \frac{4}{3} \rfloor$
     * 右侧净留黑空间 $W_{black} = W_{screen} - W_{game}$
       * 1080p: $W_{black} = 1920 - 1440 = 480\text{px}$（HUD 默认宽 380~420px）
       * 2K (1440p): $W_{black} = 2560 - 1920 = 640\text{px}$（HUD 默认宽 450~520px）
       * 4K (2160p): $W_{black} = 3840 - 2880 = 960\text{px}$（HUD 默认宽 600~720px）
   * **可视化微调预览：** 启动配置窗内提供交互式滑动条与视口缩略图，用户可直观微调 HUD 宽度、X/Y 偏移量及缩放比例，配置自动持久化。

3. **纯只读内存实时雷达（Real-time Safe Memory Engine）：**
   彻底废除受制于每年 1 月内政才能存盘的陈旧 `SAVE*.DAT` 文件监听机制。以 Windows 原生只读访问权限（`PROCESS_VM_READ`）建立 500ms 周期快照，零注入、零内存写入、绝不引发老游戏内存越界崩溃。全图逃将流动、城防预备兵消长、武将忠诚度变化实时穿透呈现。

## Key Assumptions to Validate（待验证核心假设）
- [ ] **假设 1（多屏与视口对齐生效）：** `cnc-ddraw` 在 DirectDraw 窗口化/无边框模式下，通过绝对虚拟屏幕坐标（包含副屏负坐标或大于主屏宽度的 X 偏移）能准确在目标副屏左缘拉起。
  - *验证方式：* 阶段二编写多显示器虚拟坐标生成器与环境拉起实测。
- [ ] **假设 2（x86 内存基址稳定性）：** Sango2 原版（1.05 版）中 400 武将数组与 60 城池数组在不同 Windows 10/11 系统的 ASLR 机制下基址或特征码（AOB Pattern）具备确定性。
  - *验证方式：* 阶段三编写内存特征码扫描探针验证定位命中率 100%。
- [ ] **假设 3（零崩溃承诺）：** 纯只读 `ReadProcessMemory` 在游戏频繁换图、进出战场、播放法术动画期间保持 0 异常、0 卡顿。
  - *验证方式：* 长时间挂机与剧烈战役连续压力测试。

## MVP Scope（阶段 MVP 边界）

### 包含在内（In-Scope）
* **典籍手册（离线可用）：** 400 武将 1~40 级技能长卷、拼音快速检索、全神兵图鉴、兵种相克八卦罗盘。
* **一体化启动：** 游戏路径配置、`ddraw.dll` 自动部署、`cnc-ddraw.ini` 左置参数配置、一键启动 Sango2。
* **实时雷达：** 游戏进程附加、400 武将实时忠诚/HP/MP/状态、诸侯领地城防虚实、在野寻贤与逃将追踪。
* **古风设计：** 汉末五色体系、朱砂印信渲染器、仿真古木卷轴排版。

## Not Doing（明确不做事项与取舍权衡）

- **不做任何保姆式决策说教（坚持纯客观事实）：**
  - *原因：* 策略游戏的终极乐趣在于“玩家作为主公/军师的自主权衡”。系统绝不弹窗提示“建议此时离间关羽”或“此战宜用弓兵”。
- **不做任何窗口焦点劫持与强行暂停逻辑：**
  - *原因：* 复杂的 Win32 焦点劫持容易导致打字死锁、切屏黑屏甚至 DirectDraw 渲染表面丢失。保持标准置顶与独立交互才是 20 年老游戏稳定运行的最坚固护城河。
- **不做任何内存写入、修改器或注入 Hook：**
  - *原因：* 天机阁是“军师参谋台”，不是“金手指修改器”。任何向游戏进程写内存的行为都会增加老游戏闪退几率，违背稳定至上的底线。
- **不做存档文件监听（Abandon SAVE*.DAT）：**
  - *原因：* 存档频率极低（每年一月），无法反映战时实时情报，且存在并发文件锁崩溃风险，完全由只读内存快照取代。
