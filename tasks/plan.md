# 实施规划：《群英策·天机阁》古风数字化军师参谋系统

## 一、 项目概述

《群英策·天机阁》是专为经典单机策略游戏《三国群英传2》打造的**一体化古风军师启动台与纯客观实时战局 HUD**。
本规划依据 [docs/ideas/tianjige.md](file:///d:/OneDrive/Projects/Game_Master/sanguo2_tianjige/docs/ideas/tianjige.md) 的方案沉淀与 [SPEC.md](file:///d:/OneDrive/Projects/Game_Master/sanguo2_tianjige/SPEC.md) 的架构规范书展开，彻底解决黑边遮挡、焦点死锁及存档数据滞后问题。

## 二、 架构决策与能力模块映射 (Capability Traceability)

所有研发任务均严格溯源至 [SPEC.md](file:///d:/OneDrive/Projects/Game_Master/sanguo2_tianjige/SPEC.md) 中的五个核心能力模块：

| 模块 ID | 架构决策 (Architecture Decision) & 考量依据 (Rationale) |
| :--- | :--- |
| `core-models` | **不可变领域实体与对齐映射：** 静态典籍使用 C# `record` 保障数据只读无副作用；内存结构体采用 `[StructLayout(LayoutKind.Sequential, Pack = 1)]` 精确匹配 x86 二进制镜像。 |
| `static-lore` | **毫秒级离线大典：** 采用嵌入式 JSON 资源 + 预热倒排索引，拼音首字母检索引擎过滤耗时 < 5ms，点击技能瞬间反查全图武将清单。 |
| `cnc-launcher` | **左置 1440x1080 释放 480px 空间：** 通过配置 `cnc-ddraw.ini` 将游戏视口靠左（`posX=0`），实现 1080p 屏幕下 100% 物理零遮挡，并作为一键启动台管理进程生命周期。 |
| `memory-radar` | **纯只读安全观察者引擎：** 彻底废除陈旧的 `SAVE*.DAT` 文件监听，以 `PROCESS_VM_READ` 权限 500ms 周期快照 400 将与 60 城数据，零写入、绝不引发游戏崩溃，实现真·实时战略雷达。 |
| `advisor-ui` | **汉末五色美学与极简防崩溃置顶：** 采用绢帛沉木（`#1F1A16`~`#2B241E`）、简帛素米（`#E6DAC0`）与朱砂印章体系，放弃脆弱的焦点拦截，保持标准置顶与独立交互。 |

## 四、 风险识别与应对措施

| 风险项 | 影响等级 | 应对策略 |
| :--- | :---: | :--- |
| **Windows 默认字体兼容性** | 中 | 标题默认优先选用“隶书”、“华文中宋”，若系统缺失则优雅降级为“楷体”/“微软雅黑”并附带自绘字重，确保古风庄重感不失真。 |
| **Sango2 不同版本的内存基址漂移** | 高 | 采用特征码 AOB 扫描定位武将数组与城池数组指针，不写死绝对基址，确保 1.0/1.05 原版及常规 Mod 均能精准识别。 |
| **多显示器（双屏/副屏坐标偏移）** | 中 | 通过 Win32 `EnumDisplayMonitors` 获取各屏幕虚拟工作区，以可视化卡片供玩家点选目标屏，自动将 `posX = monitor.Bounds.Left` 写入 ini 并联动天机阁贴靠目标屏右缘。 |
| **UAC 管理员权限限制** | 中 | 若游戏以管理员权限运行，在主启动器检测到 `ERROR_ACCESS_DENIED` 时给予优雅弹窗引导，或在启动器清单中配置一致权限。 |
| **屏幕分辨率非 1080p（如 2K / 4K）** | 低 | 启动器内置计算公式：根据当前显示器分辨率等比缩放 4:3 视口宽度，并动态分配右侧黑边宽度，自适应各种显示设备。 |

## 五、 阶段一验收标准（Checkpoint 1）

1. **视觉规范：** 完美呈现绢帛沉木（`#1F1A16`~`#2B241E`）、朱文印章（【无双】、【良将】等）、简帛素米排版，无任何违和现代扁平感。
2. **检索能力：** 毫秒级支持拼音首字母搜索（如输入 `gy` 即刻精准定焦关羽）。
3. **长卷展开：** 完整展示 1~40 级技能树（武将技赤红、军师技幽蓝），技能消耗与效果客观展示，点击技能可逆向拉取掌握该技能的武将清单。
4. **兵机罗盘：** 能够清晰呈现朴刀/长枪/弓箭/铁骑等兵种克制关系及八门阵型站位特征。
5. **独立可用：** 在未启动游戏的情况下，独立运行即为一套极具古典美感的三国桌面大典。
